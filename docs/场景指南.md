# 第 8 章 · 履约验收与支付协同 场景指南

## 1. 场景目标

面向财采资一体化闭环的合同、质疑、进口免税与归档协同系统；中标通知书与合同流式生成、合同与招标文件一致性校验、OCR 扫描件解析与八维度风险审查、7 个工作日质疑时限核查。

## 2. 能力清单

- 中标通知书与合同正文的流式生成及关键字段回填
- 合同与招标文件、中标结果的一致性校验
- 扫描件 OCR 混合解析与合同八维度风险审查（主体、价款、期限、验收、违约、争议、签章、附件）
- 质疑投诉 7 个工作日期限核查与防泄密校验
- 进口免税专项、3 年监管期与 15 日归档移交、全链条项目状态台账

## 3. 环境准备

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python app.py                              # http://localhost:5001
# reference/ 为算法参考实现，无需安装即可阅读
```

## 4. 核心模块索引

- `app.py`：/review_contract、/analyze_contracts、/full_chain_link
- `app.py::_get_baidu_ocr_token`：扫描件 OCR 令牌与 300DPI 识别
- `reference/contract.ts`：中标通知书与合同生成逻辑（TypeScript 参考）
- `reference/contractAudit.ts`：合同八维度审查定义
- `reference/inquiry.ts`：质疑时限与工作日计算
- `reference/importGoods.ts`：进口免税与归档移交

## 5. 演练步骤

1. 按第 3 节启动服务并确认健康检查通过。
2. 按 `examples/README.md` 中的示例调用本章核心接口。
3. 对照书中该章「实践案例」的界面截图核对返回结果。
4. 修改规则清单或提示词后重跑，观察结果差异；把本单位制度语料接入后再评测一次。

## 6. 验证点

- 返回结果是否带证据片段/行号锚点，能否回指到原文；
- 关键字段是否通过防幻觉校验，空白字段是否被标为「待确认」而非自动补值；
- 规则清单中的各项是否都有明确命中或未命中结论；
- 全过程是否留痕、结果是否可复现。

## 7. 常见问题

| 现象 | 排查方向 |
|---|---|
| 接口返回密钥错误 | 检查 `.env` 是否填写、变量名是否与 `.env.example` 一致 |
| 扫描件无文本 | 确认 OCR 服务已开通、扫描分辨率不低于 300 DPI |
| 生成结果出现旧项目信息 | 清空模板占位内容，启用防幻觉校验并人工复核 |
| 端口被占用 | 修改启动命令中的端口号，生产环境关闭 `debug=True` |
